Pengaturan

Koneksi database Firebase (Firestore) sudah dipatenkan untuk akses multi-device.

Koneksi Firebase (Paten Multi-Device)
Koneksi Paten Aktif: Terhubung otomatis ke Firebase Project sbr-putra-food di semua perangkat tanpa perlu input ulang.
API Key & Project ID sudah tertanam permanen di aplikasi untuk kemudahan akses multi-device.
Koneksi Paten Aktif: Project sbr-putra-food · Koleksi pembayaran_gas.
Informasi Multi-Device & Printer
1. Database Multi-Device: Seluruh transaksi yang disimpan atau dikoreksi langsung tersinkron ke Cloud Firestore sbr-putra-food.
2. Koreksi Data: Transaksi yang sudah disimpan dapat dikoreksi kapan saja melalui tombol ✎ Koreksi setelah simpan, di tabel Riwayat, atau di Detail Pembayaran.
3. Sinkronisasi Harga Otomatis: Perubahan harga tabung 12KG & 5KG otomatis disimpan ke koleksi pengaturan agar sama ketika dibuka di HP/perangkat lain.
4. Web Bluetooth Printer: Mendukung 3 mode kertas (58mm, 80mm, dan 58mm Admin Auto-Cutter dengan pengaturan geser kanan).
