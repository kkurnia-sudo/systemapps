Pengaturan

Koneksi database Firebase (Firestore). Disimpan di browser ini.

Koneksi Firebase
Firebase Console → Project settings (⚙) → General → Web API Key.
Biarkan (default) kecuali Anda membuat database khusus.
Belum ada konfigurasi tersimpan.
Langkah Setup
1. Di Firebase Console → Build → Firestore Database → Create database (pilih region terdekat).
2. Buka file firestore.rules di folder ini, tempel ke tab Rules Firestore lalu klik Publish.
3. Di tab Indexes, buat indeks komposit yang tercantum di firestore.indexes.json.
4. Salin Project ID & Web API Key, tempel di kolom sebelah kiri, klik Uji Koneksi.
5. Pindahkan data lama dengan perintah:
node migrate-pembayaran-gas.mjs --dry-run lalu tanpa --dry-run.
Koleksi yang dipakai: pembayaran_gas (arsip) & pengaturan (harga).
Perhatian: tanpa login, siapa pun yang mengetahui konfigurasi ini bisa membaca & menghapus data. Aturan harus dibuka; jangan pakai aplikasi ini untuk data sensitif.
