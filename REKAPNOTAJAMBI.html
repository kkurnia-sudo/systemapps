Tindakan Wajib Pasca-Restore/Reset (Reset Sequence)

Jika Anda melakukan Overwrite atau Reset, urutan ID (auto-increment) di database Supabase bisa bertabrakan. Salin script SQL di bawah ini dan jalankan di menu SQL Editor pada dashboard Supabase Anda.

-- Reset urutan ID untuk tabel Item Invoices
SELECT setval(pg_get_serial_sequence('invoice_items_jambi', 'id'), COALESCE((SELECT MAX(id) FROM invoice_items_jambi), 1), false);

-- Reset urutan ID untuk tabel Pembayaran Invoices
SELECT setval(pg_get_serial_sequence('invoice_payments_jambi', 'id'), COALESCE((SELECT MAX(id) FROM invoice_payments_jambi), 1), false);
